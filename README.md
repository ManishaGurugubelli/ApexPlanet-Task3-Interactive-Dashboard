# ApexPlanet Data Analytics Internship – Task 3

## Deep-Dive Analysis & Interactive Dashboard

This repository contains my submission for **Task 3** of the **ApexPlanet Data Analytics Internship**.

## Objective

To perform a deep-dive business analysis and develop an interactive dashboard using Microsoft Power BI for business decision-making.

## Tools Used

- Microsoft Power BI
- Microsoft Excel
- Data Analysis
- Business Intelligence

## Dashboard KPIs

- Total Revenue
- Total Orders
- Total Quantity Sold
- Average Order Value
- Average Customer Age

## Dashboard Features

- Monthly Sales Trend
- Revenue by Category
- Revenue by City
- Top Products by Revenue
- Gender Distribution
- Interactive Slicers:
  - Month
  - Category
  - City

## Key Insights

- Electronics generated the highest revenue.
- Laptop and Mobile were among the highest-performing products.
- Sales performance varied across different months.
- Revenue distribution differed across cities.
- Interactive filters allow dynamic exploration of sales data.
